1. Mission & Vision

Chain Bank bridges ancient faith traditions with modern blockchain technology. We provide a transparent, secure, and decentralized platform for spiritual acts: candles, prayers, donations, confession, and charity. Our mission is to make faith accessible to the digital generation while maintaining full respect for religious traditions.

2. Ecosystem Overview

Chain Bank consists of two branches:

  • Orthodox Branch – for Eastern Orthodox Christians (tokens: BOG, USVT, DEMON)
  • Catholic Branch – for Roman Catholics (tokens: VBDT, VBST, VBDC)

Each branch operates independently but shares the same technological foundation — Solana blockchain with Token-2022 standard.

4. Core Mechanics

  • For God: Send USVT/VBST to God's address → light a candle (1 hour)
  • Against God: Send BOG/VBDT to DEMON/DIABOLUS address → appear on the "Sinners Wall"
  • Eternal Candle: Send USVT+DEMON or VBST+VBDC to God's address → eternal candle (never expires)
  • 40+ Spiritual Deeds: Various actions (prayers, memorials, donations, NFT icons, pilgrim certificates)
  • Confession: Anonymous confession with automatic answer from the database
  • DAO: Token holders can vote on treasury allocation and project development

5. Tokenomics

  • Total supply per token: 10,000,000,000 (10 billion)
  • Decimals: 9
  • Standard: Solana Token-2022
  • Transfer fee: 0% (free transfers)
  • Mint & Freeze authorities: Revoked (fixed supply)

6. Roadmap

Q1 2025: Token creation (BOG, USVT, DEMON, VBDT, VBST, VBDC), website launch, basic mechanics (For God / Against God / Eternal Candle)
Q2 2025: 40 Spiritual Deeds, Confession page, DAO voting, Charity funds, Memory Book
Q3 2025: NFT icons, Pilgrim tracker, Parish support program, Mobile app (view-only)
Q4 2025: Integration with real churches (donations in fiat), Partnerships with Orthodox/Catholic organizations, Multi-language marketing campaign

7. Revenue Model

  • Token sales: Users buy tokens on DEX (Meteora, Jupiter)
  • Transaction fees: None (0% transfer fee) — but users pay Solana gas fees
  • Future optional services: Premium confession (chat with a real priest), parish subscriptions, banner advertising

8. Security & Transparency

  • All token contracts are verified on Solscan
  • Mint and freeze authorities are revoked — no one can mint new tokens or freeze wallets
  • All transactions are recorded on Solana blockchain and publicly visible
  • No central control — the website only provides a convenient interface for interacting with smart contracts
